# Images

Put photos here and push. The site picks them up automatically; you don't need to change any code.
Products without a photo keep showing their icon.

| Folder | File name | Size |
|---|---|---|
| `products/` | product ID, e.g. `m1.jpg`, `h4.png` | square, about 1024×1024 |
| `hero/` | `hero-1.jpg` (Diwali), `hero-2.jpg` (phones), `hero-3.jpg` (books) | wide 21:9 or 16:9, keep the left half plain, as the headline sits there |

`.jpg`, `.png` and `.webp` all work. Use lowercase names.
