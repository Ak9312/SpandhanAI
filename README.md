# SpandhanAI · Spandhan storefront

A demo Indian e-commerce homepage, built as a learning project. Its layout follows a big marketplace homepage, but it uses an original brand: the Spandhan name, a teal-and-marigold palette, and fictional products.

## What's in it
- A sticky header with a delivery location, category search, account links and a live cart counter
- A scrollable category bar
- A hero carousel that autoplays, with arrows and dot navigation
- Category tiles that overlap the hero
- Product shelves for Today's Deals (with a countdown), Home & Kitchen and Books, with ₹ pricing, M.R.P. strike-through, ratings and Add to cart buttons
- A full footer with Back to top
- Light and dark themes and a responsive layout down to phone width

## Run it
It's a single self-contained file with no build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

To host it on GitHub Pages: go to **Settings → Pages**, choose **Deploy from a branch**, and select `main` / root.
